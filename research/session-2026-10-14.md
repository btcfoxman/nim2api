# NIM 网页协议监听（2026-10-14）

- 浏览器：`nim-01.bat` 启动的 Chrome 154，CDP `127.0.0.1:9339`，账号代理 `socks5://127.0.0.1:20001`。
- 监听器：`tools/cdp_structured_listener.py`；原始结构日志留在本机 `research/captures/`，公开仓库仅保留本摘要。
- 记录六笔成功创建的视频请求，分别为 Seedance 2.0 Mini/Fast/标准、2.5 标准、Wan 3.0、Minimax H3。六笔最终均有 `finishedAt` 和 `wf-output/...mp4`。

## 账号与上传

- `GET /api/credits/getUserCreditsData` 返回 `subCredits.count`、`cpCredits.count`、`packCredits.count`、`grantCredits.count`、`uid`。可用余额为四类 count 之和；实测此账号从 4500 降到 4025。
- `POST /api/files/upload` 使用浏览器同源 multipart FormData 的 `file` 字段。图片至少 300×300。成功 HTTP 201，返回 `fileId`、`filePath`（`wf-input/...`）；图片另有 `previewPath`，视频另有 `firstFramePath`。
- 上传验证：独立 320×320 PNG 实测 HTTP 201，返回 `wf-input/...jpg`。
- 全程经账号浏览器与其代理连接 NIM。账户会话由浏览器 profile 保持，网页端无须长期打开管理窗口。

## 提交与结果

- `POST /api/workflows/start`，成功 HTTP 201。主要字段：`type=image2video_dc`、`positive`、`negative`、`enhancePrompt`、`seed`、`mediaLength`（毫秒）、`requestedAspectRatio`、`generateAudio`、`resolution`、`projectId`、`basedOn`、`source`、`meta`、`externalModel`、`isPrivate`。
- `meta.advancedMode`：Seedance 2.0 为 `seedance.v2fal`，2.5 为 `seedance.v25`，Wan 为 `wan.v30`，Minimax 为 `minimax.h3`。
- `meta.structuredFileInputs` 是 `image_urls`、`video_urls`、`audio_urls` 组；每组有 `paths` 与 `durations`，音频还带 `displayNames`。提示词引用形式是 `@image1`、`@video1`、`@audio1`。
- `externalModel`：Mini=`falBytedanceSeedance2.0MiniReferenceToVideo`，Fast=`seedanceV2FastImageToVideo`，标准=`seedanceV2ImageToVideo`，2.5=`seedanceV25ImageToVideo`，Wan=`wan30Reference2Video`，Minimax=`minimaxH3FastReferenceToVideo`。
- 创建响应包含 `workflow.id`、`error`、`parallelLimitReached`、`creditsCharged`。`GET /api/workflows/recentWorkflows` 返回任务数组；根据 `finishedAt` / `erroredAt` 与 `output` 判断状态。结果路径 `wf-output/...mp4` 可由 `https://static.nim.video/output/` 获取，已实测 Range 请求 HTTP 206。
- 近似余额差：Mini 50、Fast 80、标准 100、2.5 150、Wan 30、Minimax 65；这些是当次不同模型/时长/素材组合的实耗，不能直接作为所有规格统一价格。

## 模型元数据与边界

`GET /api/models/by-name/{externalModel}` 可查询允许的分辨率、时长、比例及网页参考报价。Mini 支持 480/720p、4–15 秒；标准 2.0 支持 480/720/1080p/4k；2.5 支持 480/720/1080p、4–30 秒；Wan 支持 480/720/1080p、2–30 秒但不含 21:9；Minimax H3 支持 480/768p、5–15 秒。各类素材单独上限按需求分别为 9/3/3、30/10/10、10/5/5、9/3/3。3.5 pre 真实验收另发现 `maxFiles` 约束图片与视频合计：Mini 6 图+3 视频可提交，7 图+3 视频和 9 图+3 视频均被 `backend params validation error` 拒绝；六个模型的元数据分别给出 9、30、10、9 的合计值。Mini 2 图+1 视频+1 音频经服务成功生成并返回视频。

该轮页面没有触发每日积分领取接口，也没有遇到 Cloudflare/429/验证码，因此不推断领取 RPC 或风控绕过参数。账户需要网页验证时在管理页保持人工完成。
